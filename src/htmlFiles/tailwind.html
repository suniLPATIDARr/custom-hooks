What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework for rapidly building custom user interfaces. Instead of writing traditional CSS stylesheets with classes and selectors, you use small, atomic utility classes directly in your HTML to style elements.

Key Idea: Utility-First

  • Tailwind provides hundreds of tiny CSS classes like: p-4 (padding 1rem), text-center (center text), bg-blue-500 (blue background), and layout utilities like flex, grid, items-center.
  • These classes can be composed directly in your markup, avoiding the need for custom CSS most of the time.

Why Tailwind CSS?

Benefit Explanation
Rapid UI Development Build layouts fast without writing CSS
No naming battles No more arguing about class names or CSS specificity
Highly customizable Use configuration files to define your design system
Responsive & state variants Add classes for mobile, hover, focus, dark mode etc. easily
Low specificity issues Utility classes have low CSS specificity and don’t conflict much
Small CSS bundle With purging unused styles, output CSS is tiny and fast

How Tailwind CSS Works

  1. Install Tailwind in your project (via npm, CDN, or frameworks like Next.js).
  2. Use utility classes in your HTML/JSX.
  3. Run build process to generate CSS with only the used classes.
  4. Tailwind applies styles via generated CSS classes.

Example

<button class="bg-blue-500 hover:bg-blue-700 text-white font-bold py-2 px-4 rounded">
  Click me
</button>

Explanation:

  • bg-blue-500: blue background
  • hover:bg-blue-700: darker blue on hover
  • text-white: white text
  • font-bold: bold font
  • py-2 px-4: vertical & horizontal padding
  • rounded: rounded corners

Customizing Tailwind

module.exports = {
  theme: {
    extend: {
      colors: {
        primary: '#1DA1F2',
      },
    },
  },
  variants: {},
  plugins: [],
};

You can add your own custom colors, fonts, spacing, enable variants (focus, hover, dark mode), and use plugins.

Responsive Design

Tailwind includes built-in responsive prefixes:

Prefix Screensize Example
sm: ≥ 640px sm:text-lg
md: ≥ 768px md:bg-red-500
lg: ≥ 1024px lg:flex
xl: ≥ 1280px xl:grid
2xl: ≥ 1536px 2xl:container

State Variants

Tailwind supports many variants like hover:, focus:, active:, disabled:, dark:, etc.

<button class="bg-green-500 hover:bg-green-700 focus:outline-none focus:ring-4 focus:ring-green-300">
  Submit
</button>

Summary

Tailwind CSS is a modern, utility-first CSS framework that makes styling faster, easier, and more consistent by using small reusable utility classes instead of custom CSS rules. It supports responsive design, theming, and state variants out of the box, and can be fully customized to fit your project's design system.
