📋 Cheat Sheet

Selector / Property Description Example
document.getElementById(id) Selects an element by ID document.getElementById('app')
document.querySelector() First match using CSS selector document.querySelector('.box')
document.querySelectorAll() All matches using CSS selector document.querySelectorAll('li')
element.children Child elements (no text nodes) parent.children
element.childNodes All child nodes (includes text) parent.childNodes
element.firstElementChild First child element parent.firstElementChild
element.parentNode Parent node child.parentNode
element.nextElementSibling Next sibling element el.nextElementSibling
element.appendChild() Adds a new child el.appendChild(newDiv)
element.removeChild() Removes a child el.removeChild(child)
element.replaceChild() Replaces a child el.replaceChild(new, old)
document.createElement() Creates a new element document.createElement('div')
element.textContent Gets or sets text el.textContent = 'Hello'
element.innerHTML Gets or sets HTML el.innerHTML = '<b>Hi</b>'
